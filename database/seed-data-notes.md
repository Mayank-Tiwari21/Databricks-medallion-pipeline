# Seed data notes

Source CSVs live in `data/`. They are synthetic (Faker + random); no real PII.

Generated by `src/data_generation/generate_sample_data.py`:

| File | Rows | Notes |
|---|---|---|
| `customers.csv` | 10,000 | Seed 42 |
| `products.csv` | 500 | Seed 43 |
| `orders.csv` | 100,000 | Seed 44; most FKs valid; seeded nulls/orphans/dup PKs |

`orders.total_amount` is computed as `quantity * unit_price`.
`orders.payment_date` is blank when `order_status = Pending`.

Most `orders.customer_id` / `orders.product_id` values exist in the parent
files; Prompt 3 plants known nulls and orphans for Silver to flag.

Seeded quality issues (Prompt 3) are documented in
`src/data_generation/DATA_GENERATION_NOTES.md` and
`data-quality-strategy.md`. Re-run the generator after changing injection
counts.
