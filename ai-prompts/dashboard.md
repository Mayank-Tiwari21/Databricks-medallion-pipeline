# Prompt — dashboard

## Prompt 1 (queries)

Write dashboard_queries.sql: 3 queries for a Databricks SQL Dashboard —
(1) Top 10 products by revenue for a bar chart,
(2) customer revenue distribution bucketed for a histogram,
(3) customer segment counts/revenue for a pie chart.
Query from the Gold tables only. Keep each query self-contained and name columns clearly for chart
labeling.

## Prompt 2 (guide)

Write DASHBOARD_GUIDE.md: step-by-step instructions for creating each visualization in Databricks SQL
from these queries, including which chart type and axis/field mapping to select, and how to add a
date-range or segment filter.
